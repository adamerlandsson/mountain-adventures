# My Mountain Adventures

A simple, beautiful blog for sharing mountain hiking and adventure stories.

## How to use

1. Open `index.html` in your browser to view the blog
2. To add a new post, duplicate the `<article class="post">` block in `index.html` and fill in:
   - The date
   - The post title
   - The image URL or local image path
   - Your adventure story text
3. To use your own photos, drop them in the `images/` folder and update the `src` attribute in the HTML

## Features

- Simple, clean design with no dependencies
- Fully responsive (works on mobile, tablet, desktop)
- Easy to customize — just edit the HTML and CSS
- Beautiful gradient background and hover effects

Enjoy sharing your adventures! 🏔️
